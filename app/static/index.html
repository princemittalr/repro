Repro Show it the bug. It ships the fix.

From screen recording to merged-ready fix.

Drop in a recording of a bug. Repro watches it, writes a Playwright test that fails on the bug, fixes the code until the test passes, and opens a pull request with the evidence. Powered by NVIDIA Nemotron on Nebius Token Factory, with live research by Tavily.

Try a sample video

1. Perceive and reproduce

Nemotron 3.5 Super VL reads the recording; Nemotron 3 Super turns it into a Playwright test that fails on the bug.

2. Fix and verify

A tool-using agent patches the code until the test is green and the existing suite still passes, escalating to Nemotron 3 Ultra if needed.

3. Ship

A pull request with the fix, the new regression test, timestamped repro steps and the red/green evidence.
