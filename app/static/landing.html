The problem

Bug reports are videos.
Fixes need tests.

"It does this, see attached." Turning that clip into a fix means watching it, working out the exact steps, reproducing it, writing a test, finding the root cause and proving the fix. Usually across days of back-and-forth.

The usual loop
  1. Ticket: "Coupon applies twice?" + bug.mp4
  2. Dev: "Can't reproduce. What were the exact steps?"
  3. QA: re-records, adds notes, waits
  4. Dev: reproduces, digs for the root cause, maybe writes a test
  5. Review: "How do we know it's fixed?"

Days.

How it works

From red to green, on its own.

Every claim in the pull request is backed by a test that went from failing to passing.

  1. 1

    Record

    Capture the bug with any screen recorder. No steps to write down.

  2. 2

    Reproduce

    Repro reads the video and writes a Playwright test that fails on the bug.

  3. 3

    Fix

    A tool-using agent patches a copy of the code until that test passes.

  4. 4

    Verify

    The new test and the existing suite run again. Both must be green.

  5. 5

    Ship

    A pull request with the fix, the test, timestamped steps and the evidence.

Features

An engineer's whole bug loop, automated.

Understands the video

Keyframes just before and after every visible change, a per-frame transcript and a deterministic diff turn pixels into exact steps.

t=11.94s click Apply → Discount −$3.25 → −$6.50

Routes each step to the right model

Small and fast where it can be, the largest model only when the coder fails twice.

Writes the failing test first

A Playwright test, run in a sandbox, kept only if it is red on the bug.

def test_repro(page, base_url):
    page.goto(base_url)
    page.get_by_test_id("add-tee").click()
    page.get_by_test_id("add-mug").click()
    page.get_by_test_id("coupon-input").fill("SAVE10")
    page.get_by_test_id("apply-coupon").click()
    discount = page.get_by_test_id("discount").inner_text()
    page.get_by_test_id("coupon-input").fill("SAVE10")
    page.get_by_test_id("apply-coupon").click()
    expect(page.get_by_test_id("discount")).to_have_text(discount)
